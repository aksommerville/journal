# All Games I've Finished

Started keeping this list 2026-05-10.
I started making games around 1992 but pretty much everything before 2005 or so has been lost.
(which I'm sure is for the best).
Incomplete games won't be included here, though the definition of "complete" may be fuzzy.
Very old ones are more precious so they enjoy a looser standard.
Not everything here has been published.
I started using Itch around 2023, so from there on, the standard can be whether it's published on Itch.

Platform "Native" means a divorcible I/O stack, usually SDL or something homemade,
such that it could be built for new targets without much effort.
"Mac" means native 68k or PowerPC from before MacOS 10. I'd call 10+ "OSX", but there aren't any.

Size is "BUNDLE / LOC".
BUNDLE is the Egg ROM size, unpacked size of a Linux distribution, or whatever makes sense for the game.
LOC is the naive line count (`wc -l $(find src -name '*.[ch]' -or -name '*.js')`). Include tooling etc.
